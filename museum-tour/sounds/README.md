# Puzzle sound effects

UI effects by Kenney, licensed under CC0 1.0.
Original pack: https://kenney.nl/assets/interface-sounds
WAV distribution: https://github.com/Calinou/kenney-interface-sounds
License: LICENSE.txt

- ui-click.wav: icon / interface click (UI Audio mouseclick1.wav)
- click_003.wav: pick up puzzle piece
- drop_002.wav: swap puzzle pieces
- confirmation_002.wav: puzzle completed
- ui-close.wav: close game (UI Audio mouserelease1.wav)
- back_001.wav: reshuffle

Firework bursts are synthesized locally with Web Audio in puzzle-effects.js.
Puzzle-piece landing uses a short synthesized wooden tap, synchronized to each piece's entrance animation.
No background music is included.
